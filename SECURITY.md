# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.1.x   | Yes                |
| 2.0.x   | Yes                |
| < 2.0   | No                 |

## Reporting a Vulnerability

If you discover a security vulnerability, medical data privacy exposure risk, or algorithmic flaw within this codebase:

1. Do NOT file a public issue on GitHub.
2. Email the principal author privately at: cornelioabdimash@gmail.com
3. Include the following details in your report:
   - Type of vulnerability (e.g., credential leak, buffer overflow, uncontrolled dependency injection).
   - Exact file path and line numbers.
   - Proof of concept or reproduction steps.
   - Proposed remediation if available.

We will acknowledge receipt within 48 hours and work with you to implement and verify a patch before public disclosure.
